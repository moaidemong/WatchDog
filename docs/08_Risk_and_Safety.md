# 08. Risk and Safety

## 1. 기본 인식
이 시스템은 반려견 안전을 돕는 **보조 시스템**이다.
의료기기나 완전무결한 감시 시스템으로 간주하면 안 된다.

## 2. 주요 위험
### 2.1 미탐(False Negative)
가장 중요한 위험이다.
실제 기상 실패가 있었는데 알림이 오지 않는 경우.

원인 예:
- 카메라 가림
- 야간 화질 저하
- 이불/쿠션에 가려 keypoint 추정 실패
- threshold가 너무 보수적
- 해당 유형 샘플 부족

대응:
- 카메라 위치 개선
- 미탐 사례 우선 수집
- pose confidence fallback 규칙 추가
- 하이브리드 센서 검토

### 2.2 오탐(False Positive)
알림이 너무 자주 오면 결국 시스템을 꺼버리게 된다.

원인 예:
- sleeping twitch를 실패 시도로 오인
- 정상 자세 변경을 collapse로 오인
- 반사/그림자/사람 개입 오검출

대응:
- alert cooldown
- recovery confirmation
- multi-condition alert
- ambiguous 클래스 도입

### 2.3 프라이버시
실내 CCTV 영상은 민감할 수 있다.

대응:
- 최소 보관 기간
- 접근 제어
- 토큰 분리
- 불필요한 외부 업로드 금지

## 3. 안전 설계 원칙
### 3.1 fail-soft
의심스럽지만 확실치 않을 때는
- 낮은 우선순위 알림
- 리뷰 큐 저장
같은 형태를 고려한다.

### 3.2 explainable alerts
왜 알림이 울렸는지 설명 가능해야 한다.
예:
- 14초 동안 low posture
- 3회 rise attempt
- standing threshold 미도달

### 3.3 human-in-the-loop
최종 신뢰성은 사람 검토를 통해 계속 보정한다.
- event review
- mislabeled correction
- threshold adjustment

## 4. 권장 운영 대책
- 카메라 1대만 믿지 말고 가능한 경우 2시점 검토
- 야간 IR 성능 확인
- 정기적으로 테스트 이벤트로 notifier 점검
- 저장공간/프로세스 상태 모니터링
- 전원/네트워크 장애 대비

## 5. 법적/윤리적 관점
- 반려견 안전 목적의 자가 시스템이라는 점을 명확히 할 것
- 제3자 공간이 포함될 경우 촬영/보관 범위 검토
- 외부 서비스 연동 시 데이터 최소화

## 6. 한계
- 본 시스템은 수의학적 상태를 진단하지 못함
- 쓰러짐의 원인을 구분하지 못할 수 있음
- 화면 밖 사건은 감지 불가
- 사람이 즉시 대응할 수 없는 상황에서는 알림만으로 한계가 있음

## 7. 향후 보강책
- 웨어러블 IMU 추가
- 소리/울음 감지 결합
- 다중 카메라
- 침대/매트/바닥 구역 위험 맵
- 보호자 부재 시 대체 연락 체계
