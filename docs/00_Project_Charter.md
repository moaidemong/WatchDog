# 00. Project Charter

## 1. 프로젝트명
Dog Rise Alert

## 2. 문제 정의
노견이 바닥에서 누운 뒤 스스로 일어나지 못하고 버둥거리거나, 쓰러진 후 정상적으로 자세를 회복하지 못하는 상황이 발생할 수 있다.

사용자가 다른 일에 집중 중이거나 외출 중일 경우 즉시 대응이 어렵다.

따라서 CCTV 영상을 기반으로 아래 상황을 자동 감지하고 알림을 보내는 시스템이 필요하다.

- 일어나려는 시도는 있으나 일어나지 못함
- 쓰러진 뒤 정상 자세로 회복하지 못함
- 일정 시간 이상 비정상적 자세/버둥거림이 지속됨

## 3. 목표
### 3.1 1차 목표
- 반려견의 **기상 실패 이벤트**를 자동 감지
- 메신저로 빠르게 알림 전송
- 집 내부 CCTV 환경에서 지속 운영 가능

### 3.2 비목표
- 모든 반려견 행동을 완벽히 분류하는 범용 행동 인식
- 의료 진단 시스템 수준의 보장
- 모든 각도, 모든 가림, 모든 조명에서 100% 정확한 인식

## 4. 성공 기준
### 4.1 기능 기준
- CCTV에서 반려견 이벤트 구간을 자동 추출할 수 있음
- 기상 실패 후보 이벤트를 분류할 수 있음
- 분류 결과에 따라 메신저 알림을 전송할 수 있음
- 운영 로그, 이벤트 클립, 라벨 결과를 저장할 수 있음

### 4.2 운영 기준
- 하루 종일 켜 두어도 안정적으로 동작
- 오탐이 관리 가능한 수준
- 미탐 사례를 다시 학습 데이터로 반영 가능
- 재학습 및 규칙 수정이 쉬움

## 5. 접근 전략
이 프로젝트는 처음부터 대형 행동인식 신경망을 새로 만드는 방식이 아니라 다음 구조를 따른다.

### 5.1 핵심 원칙
1. **탐지와 판정을 분리**
   - 개가 있는지
   - 자세가 어떤지
   - 기상 실패인지

2. **포즈 기반 해석 우선**
   - raw pixel end-to-end보다 포즈/상태 전이 기반이 샘플 효율이 좋음

3. **규칙과 모델 혼합**
   - 1차는 규칙 기반 경보
   - 2차는 경량 분류기 보강
   - 필요 시 시계열 모델 추가

4. **액티브 러닝**
   - 오탐/미탐 클립을 지속 수집하여 데이터셋 갱신

## 6. 범위
### 포함
- 실내 CCTV 영상
- 단일 반려견 기준 1차 설계
- 주/야간 운영
- 로컬 추론
- 메신저 알림
- 이벤트 클립 저장 및 검토

### 제외
- 다수 반려견 식별/개체 추적 고도화
- 반려견 외 다른 동물 확장
- 수의학적 진단 기능
- 클라우드 대규모 학습 인프라

## 7. 1차 운영 시나리오
1. 카메라에서 반려견이 감지됨
2. 반려견이 누운 상태 또는 비정상 자세 상태로 진입
3. 몸을 일으키려는 반복 시도가 관찰됨
4. 일정 시간 내 standing 상태로 복귀하지 못함
5. 이벤트 점수가 임계값 이상이면 알림 전송
6. 해당 전후 클립을 저장
7. 사용자가 검토 후 정답 라벨 부여
8. 다음 학습 주기에 반영

## 8. 기술 원칙
- 초기에는 CPU 또는 경량 GPU 환경 우선
- 큰 모델보다 해석 가능한 파이프라인 우선
- 재현성과 유지보수성을 위해 단계별 모듈 분리
- VSCode + ChatGPT 5.4 협업 기준으로 문서, 프롬프트, 코드 구조 정리

## 9. 산출물
- 데이터셋 스펙
- 라벨링 가이드
- 추론 파이프라인 코드
- 알림 파이프라인 코드
- 평가 스크립트
- 운영 대시보드 또는 최소 로그 뷰어
- 재학습 스크립트
